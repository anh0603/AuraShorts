PHẦN 1 • TỔNG QUAN KIẾN TRÚC

Cách Hệ Thống Tự Động Đăng YouTube Hoạt Động

AuraShorts OS tích hợp trực tiếp với Google YouTube Data API v3 chuẩn doanh nghiệp, cho phép tự động tải video 9:16 lên định dạng YouTube Shorts an toàn, không sợ trùng bài và không lo bị khóa kênh.

01

Chuẩn Hóa 9:16 Shorts

Kiểm tra tự động ffprobe: độ phân giải 1080x1920, thời lượng ≤ 60 giây, gắn thẻ #Shorts vào tiêu đề và mô tả.

02

Resumable Upload

Truyền tải phân đoạn (chunked) tới máy chủ Google, tự động nối lại nếu đường truyền mạng bị gián đoạn.

Chống Trùng Idempotent

Mã hóa SHA-256 nội dung; bấm nhầm nhiều lần vẫn bảo đảm chỉ có đúng 1 video duy nhất được đưa lên kênh.

PHẦN 2 • CHUẨN BỊ THÔNG TIN KÊNH

Lấy Mã Kênh (Channel ID) & Quyền Tải Lên

Hệ thống cần 3 thông tin để xác thực với YouTube API: Tên Kênh hiển thị, Mã Kênh (Channel ID) và Access Token / Refresh Token.

Bước 1

Lấy Channel ID từ YouTube Studio

Truy cập studio.youtube.com → Cài đặt (Settings) → Kênh (Channel) → Cài đặt nâng cao (Advanced settings) → Sao chép ID có dạng UC... (ví dụ: UC1234567890abcdef).

Bước 2

Tạo OAuth Token (Google Cloud Console)

Tại Google Cloud Console, kích hoạt YouTube Data API v3, tạo OAuth Client ID với scope: https://www.googleapis.com/auth/youtube.upload để cấp quyền đăng video.

💡 Mẹo bảo mật: Mọi token khi lưu vào hệ thống đều được tự động mã hóa AES và ẩn một phần (ví dụ: ya29.••••••••yt01), không bao giờ hiển thị nguyên bản ra ngoài.
PHẦN 3 • THAO TÁC KẾT NỐI TRÊN GIAO DIỆN

Thao Tác Kết Nối Kênh Trong 1 Phút

Trên thanh menu bên trái, chuyển sang trang "Quản Trị Kênh & Hàng Đợi Xuất Bản".

✓ Các bước thực hiện trong modal "+ Kết Nối Kênh":
  1. Bấm nút "+ Kết Nối Kênh" ở góc phải phía trên.
  2. Chọn nền tảng: YouTube.
  3. Nhập Tên Kênh (ví dụ: Tin Nóng 24h Shorts).
  4. Nhập Channel ID (mã UC... vừa lấy ở Bước 2).
  5. Dán OAuth Access Token hoặc API Key được cấp.
  6. Chọn Chủ đề (Niche): Công nghệ, Tin tức xã hội, Tài chính...
  7. Bấm "Xác Nhận Kết Nối".
Kiểm tra kết nối: Bấm nút "Test" trên thẻ kênh

Bấm "Duyệt"
